# Climbhub AT Protocol Lexicons

This directory defines the AT Protocol Lexicon schemas used by Climbhub under `app.climbhub.*` and the general-purpose `org.openstreetmap.*` namespace.

Note that the general-purpose `org.openstreetmap.*` namespace is not specific to Climbhub, and is intended for use by any application that wants to use the AT Protocol comment and review osm data.
